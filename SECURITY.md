# Security Policy

## Reporting a vulnerability

If you find a security issue in a rule (for example, a fix pattern that could introduce a vulnerability instead of removing one), please report it privately rather than opening a public issue.

Use GitHub's [private vulnerability reporting](https://github.com/x185plus/x185plus-forge/security/advisories/new) for this repository, or open a draft security advisory. Please include:

- The affected rule file(s)
- The unsafe input/output pair that demonstrates the problem
- Suggested fix, if you have one

## Scope

This policy covers the rule definitions and JSON schema in this repository. It does not cover the X185Plus scanner or platform itself.

## Response

We aim to acknowledge reports within a reasonable timeframe and will credit reporters in the fix commit unless anonymity is requested.
